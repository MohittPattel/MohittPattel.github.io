# Mohit Patel — Portfolio

Modern responsive portfolio for GitHub Pages.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Run locally
Open `index.html` in a browser, or use any static HTTP server.

## GitHub Pages
Push the contents of this folder to the repository and enable GitHub Pages from the repository's Pages settings.

## Before publishing
Update the placeholder email and social profile URLs in `index.html`.
